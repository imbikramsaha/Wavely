WAVELY — ANDROID LAUNCHER ICON SET
==================================
Old logo (cyan→blue→indigo bars) on a light/white icon.

HOW TO INSTALL (Android Studio)
-------------------------------
Copy the contents of the "res/" folder into your app module's
  app/src/main/res/
merging the mipmap-* and values folders.

WHAT'S INCLUDED
---------------
res/mipmap-<dpi>/ic_launcher.png          Legacy launcher icon (white squircle + mark)
res/mipmap-<dpi>/ic_launcher_round.png    Round legacy variant
res/mipmap-<dpi>/ic_launcher_foreground.png  Adaptive-icon foreground (transparent, mark in safe zone)
res/mipmap-anydpi-v26/ic_launcher.xml     Adaptive icon (API 26+): white background + gradient foreground
res/values/ic_launcher_background.xml     Background colour (#FFFFFF)
play-store-icon-512.png                   512x512 Play Store listing icon
source/wavely-mark.svg                    Scalable vector source

Densities: mdpi 48 / hdpi 72 / xhdpi 96 / xxhdpi 144 / xxxhdpi 192 px (legacy)
           foreground 108 / 162 / 216 / 324 / 432 px

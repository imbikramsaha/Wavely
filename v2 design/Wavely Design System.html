Wavely Design System

A calm, premium foundation for an offline, on-device music player. Deep neutrals, one serene gradient accent derived from the Wavely mark, and a fallback-art system built for a library that is mostly art-less and full of long, messy titles. Dark is primary; light and Android dynamic-color are first-class. This is a Compose / Material 3 theme + component restyle — no behavior changes.

Colors · Tokens

Dark (primary)

Near-black, faintly cool neutrals keep artwork and the accent doing the talking.

Light

Soft cool-white surfaces; accent darkens to hold WCAG-AA on white.

Dynamic color (Material You): when the user enables it, map Android’s generated primary → --wv-accent, surfaceContainer* → --wv-surface 1/2/3, and onSurfaceVariant → --wv-text-2. The brand gradient stays fixed for the mark, the now-playing progress and the active-row equalizer so Wavely is still recognisable under any wallpaper palette.

Typography · Hanken Grotesk

A clean, slightly warm grotesque — premium without the over-used feel of the platform default. 4px baseline rhythm.

Iconography

One custom stroke set — 2px, round caps/joins, 24px grid. Filled variants for play / pause / favorite-on. Auto-mirrored for RTL.

Generated fallback artwork

Most tracks have no cover. Each gets a stable, unique gradient hashed from its title (so the same song always looks the same), a soft sheen, a faint waveform baseline for music identity, and a monogram from the first real character. Real embedded art simply slots into the same rounded frame when present.

Inset-safe, edge-to-edge (v1 bug fix): the screen is a column — status bar, scrollable body, then an absolutely-docked mini-player + nav that pads env(safe-area-inset-bottom). Now-Playing transport also reserves that inset. Nothing ever sits under the system bars.
Responsive: medium width → bottom nav becomes a left navigation rail; expanded/tablet → Now Playing is a persistent right side panel beside the library; landscape → Now Playing splits into a two-pane (artwork left, controls + queue right).
Accessibility: all touch targets ≥ 48dp; body/secondary text meets WCAG-AA on both themes; layouts reflow at large font scales (titles clamp to 2 lines, never truncate the secondary line away); predictive-back collapses the Now Playing sheet.
Motion: mini ⇄ full is a single physical drag (spring cubic-bezier(.22,.9,.27,1)); favorite toggle pops; rows press to 0.96; selection & drag-reorder animate; undo snackbar slides up. All gated by prefers-reduced-motion.
